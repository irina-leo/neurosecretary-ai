# neurosecretary-ai
AI system for automatic transcription, diarization and meeting report generation
# NeuroSecretary AI

Интеллектуальная многоагентная система автоматической обработки аудио- и видеоматериалов, построенная на базе OpenAI Responses API.

## О проекте

NeuroSecretary AI — это система из специализированных ИИ-ассистентов, предназначенная для автоматического преобразования аудио- и видеозаписей в структурированные отчёты, протоколы встреч, аналитические сводки и документы.

Проект полностью разработан и протестирован в Google Colab.

Архитектура построена как последовательный пайплайн взаимодействующих AI-ассистентов, где результат работы каждого этапа становится входом для следующего.

Для хранения данных и обмена результатами используется Google Drive.

Система позволяет:

* загружать аудио и видеофайлы;
* автоматически распознавать речь;
* выполнять диаризацию участников разговора;
* индексировать предложения и реплики;
* анализировать содержание беседы;
* формировать итоговые протоколы и аналитические отчёты.

## Режимы запуска

Система поддерживает несколько сценариев старта обработки:

### Audio Mode

Вход:

* аудиофайл

Результат:

* полный цикл обработки от распознавания речи до отчёта.

### Transcript Mode

Вход:

* готовый текстовый транскрипт.

Результат:

* пропуск этапа ASR и переход к аналитической обработке.

### Diarized Mode

Вход:

* транскрибированный и размеченный диалог.

Результат:

* запуск аналитических ассистентов без повторной обработки речи.

---

## Ассистент 1. ASR (Automatic Speech Recognition)

Функции:

* загрузка аудио и видео;
* подготовка файлов;
* распознавание речи через OpenAI Whisper;
* генерация транскриптов.

Результаты:

* transcript.txt
* transcript.json
* subtitles.srt
* subtitles.vtt

---

## Ассистент 2. Sentence Indexer

Функции:

* сегментация текста;
* присвоение идентификаторов предложений;
* подготовка структуры данных для анализа.

Результат:

* sentences.jsonl

---

## Ассистент 3. Speaker Diarization

Функции:

* выделение участников разговора;
* группировка реплик по говорящим;
* построение структуры диалога.

Результаты:

* diarized.txt
* utterances.json

Поддерживаемые роли:

* Interviewer
* Guest
* Unknown

---

## Ассистент 4. Semantic Analyst

Функции:

* извлечение ключевых смыслов;
* определение тем обсуждения;
* поиск решений и договорённостей;
* анализ содержания беседы.

Результаты:

* analysis.json
* analysis.md

---

## Ассистент 5. Report Generator

Функции:

* генерация итоговых материалов;
* подготовка кратких сводок;
* формирование протоколов встреч;
* создание аналитических отчётов.

Результаты:

* summary.md
* minutes.md
* report.docx

## Evidence-Based Architecture

Одним из ключевых принципов системы является проверяемость выводов.

Каждый вывод должен иметь подтверждение в исходном материале.

Для этого используются:

* sentence_id
* utterance_id

Такой подход позволяет:

* снизить вероятность галлюцинаций модели;
* обеспечить прозрачность анализа;
* повысить доверие к результатам обработки.
